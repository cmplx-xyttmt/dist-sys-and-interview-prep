## After this rung he can say

- the difference between holding a credential (the API key itself) and holding a capability (an unforgeable right to perform one action, which can be handed out and revoked)
- what a token broker is: a process that holds the real secret and performs calls on behalf of a less-trusted process, adding the secret itself. The secret usually travels as an HTTP header, `Authorization: Bearer <key>`
- why an agent's machine should never contain the raw key: anything with root on that machine (including the agent's own mistakes) can read it
- how Sprites Connectors implement this: the Sprite reaches OpenRouter (a service that fronts many language-model APIs behind one key), Slack, GitHub or any HTTP API, and the credential never enters the VM. OAuth is the web's standard way for one service to grant another limited access on a user's behalf; Connectors hide its dance too

### Step 4 · do · Mission step 1

Write `upstream.py`, about 20 lines: an HTTP server on port 9000 that returns 200 and a JSON body only if the request carries `Authorization: Bearer <REAL_KEY>`, else 401. This stands in for the real API, so no real key is at risk.

### Step 5 · do · Mission step 2

Write `broker.py`, about 100 lines: an HTTP server on port 8787 that accepts requests on `/proxy/<path>`, allows exactly one upstream host (`127.0.0.1:9000`), adds `Authorization: Bearer $REAL_KEY` from its own environment, forwards the request, and logs method, path and status.

### Step 6 · do · Mission step 3

Write `agent.py`: calls `$API_BASE/proxy/hello` and prints the status and body. With `--try-to-leak` it instead prints its own environment, searches the filesystem for the key's first eight characters, and tries to read `/proc/<broker pid>/environ`.

### Step 7 · do · Mission step 4

Separation is the point, so run the three as two users inside one Linux container: `docker run --rm -it ubuntu bash`, then `apt update && apt install -y python3 && useradd -m agent`. As root: `REAL_KEY=sk-ladder-test python3 upstream.py &` and `REAL_KEY=sk-ladder-test python3 broker.py &`. As the agent: `su agent -c 'env -i PATH=$PATH API_BASE=http://127.0.0.1:8787 python3 agent.py'`, then the same with `--try-to-leak`.
